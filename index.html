Bairros e Regiões

Registros por bairro

Valores estimados e a fonte de cada dado. Cada bairro aparece com um único tipo de registro, o que consta nos dados do projeto: isso não significa que outros tipos de violência não ocorram ali. Fontes diferentes medem coisas diferentes, por isso os números não devem ser comparados diretamente entre bairros.

Metodologia

Como calculamos o nível de atenção

O Elas na Rota mostra uma estimativa feita a partir de dados públicos. Ela ajuda a planejar o trajeto, mas não garante segurança nem substitui o seu próprio julgamento.

De onde vêm os dados

A base de dados do projeto reúne um volume estimado de registros (amostra) para cada bairro, atribuído a fontes públicas: SINAN, Sinesp, DataJud e SIM.

Cada bairro vem de uma única fonte e de um único tipo de registro. Fontes diferentes medem coisas diferentes, como ocorrências, ações judiciais e óbitos.

O DataSenado também é fonte do projeto, mas é uma pesquisa de percepção e por isso não entra no cálculo do nível por bairro.

Como o nível é definido

  • Alto: 4.000 registros ou mais.
  • Médio: de 2.500 a 3.999 registros.
  • Baixo: menos de 2.500 registros.

O nível é relativo ao que consta nos dados do projeto, e não uma medida absoluta de risco.

Como o horário entra

Os dados do projeto não têm registros hora a hora. Eles informam só a faixa de horário de maior ocorrência de cada bairro.

Se essa faixa cobre pelo menos metade do período escolhido, mostramos o nível do bairro. Fora dela, mostramos um nível abaixo. Por isso, o nível por horário é uma estimativa, não uma medição.

O que esses números não dizem

  • “Alto” quer dizer mais registros nos dados do projeto, não que o bairro seja perigoso. O número de registros também depende de quantas pessoas denunciam e de onde há delegacias, hospitais e outros serviços.
  • “Baixo” não quer dizer seguro. Muitos casos de violência não chegam a ser registrados.
  • Bairros que não aparecem não têm dados no projeto. Isso não significa que sejam seguros.
  • Cada bairro mostra um único tipo de registro, o que consta nos dados do projeto. Outros tipos de violência podem ocorrer ali.
